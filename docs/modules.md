# Proposed 14-point module plan (NOT YET EARNED)

## Major (2 points each)
1. Web: frameworks on both frontend and backend — 2
2. Web: real-time features via WebSockets — 2
3. Web: user interaction (chat, profiles, friends) — 2
4. User Management: standard user management (editable profiles, avatars, friend online status) — 2
5. Web: public API (API-key authorization, rate limits, documentation, 5+ endpoints) — 2

## Minor (1 point each)
6. Web: ORM for the database — 1
7. Web: complete notification system for creation, update and deletion actions — 1
8. Web: advanced search with filters, sorting and pagination — 1
9. Web: Server-Side Rendering (SSR) — 1

**Total proposed:** 5*2 + 4*1 = 14 points.

Important: A module is worth zero until it meets every listed condition. The team should target backup modules only after this scope is stable, e.g., custom design system with 10 reusable components, or at least two additional browsers with complete functionality.

The version 21.2 subject requires additional pages and technical/security rules independent of module points.
